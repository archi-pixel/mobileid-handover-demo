# 신분증 이어받기 시뮬레이터

「폰 바꿔도 신분증은 그대로」(2026 모바일신분증 아이디어 공모전 응모작)의 시제품
폰을 바꾸거나 3년이 지나도 다시 방문하지 않고, 옛 폰의 모바일신분증과 새 폰 얼굴 인증으로 신분증을 이어받습니다.

## 여는 법
- 이 저장소의 index.html 을 내려받아 더블클릭하거나 아래 온라인 주소로 열면 크롬·엣지 같은 웹브라우저에서 열립니다.
- 설치나 인터넷 연결이 필요 없습니다. 파일 하나로 동작합니다(외부 라이브러리·글꼴 없음).
- 온라인 주소: https://archi-pixel.github.io/mobileid-handover-demo/
- 화면 위에서 시나리오(①~⑧)를 고르고, 주황 테두리가 생긴 버튼을 차례로 누르면 됩니다. 이어받기는 새 폰에서 먼저 시작합니다.
- 「자동 시연」을 누르면 3초마다 한 단계씩 저절로 진행됩니다.
- 「+72시간」「+30일」「+3년」은 가상 시계를 앞으로 돌립니다.
- 자세한 설명은 화면 오른쪽 위 「도움말」에 있습니다.
- PC 화면(가로 1280픽셀 이상)을 권합니다. 화면 크기에 맞춰 자동으로 줄고 늘어납니다.

## 화면 구성
- 옛 폰(쓰던 폰) | 새 폰 | 공통기반 기록(모바일 신분증 중앙 시스템 역할)
- 공통기반 기록의 줄을 누르면 실제 서명값(16진수 앞부분)과 검증 결과가 펼쳐집니다. 막힌 검사는 빨간색입니다.
- 공통기반 칸의 「분실 신고 창구에서 되돌리기」: 옛 폰이 없을 때(보상판매 등) 누리집·콜센터·주민센터에서 본인 확인 뒤 새 폰 신분증을 폐기하는 경우(신분증은 방문·IC로 다시 받음)

## 시나리오 8개
① 정상 이어받기
   새 폰 얼굴을 공통기반이 바로 대조 → 새 폰에 QR → 옛 폰이 QR을 찍고 블루투스로 두 폰이 가까이 있는지 확인 → 옛 폰 승인 → 새 폰에 다시 발급. 옛 폰 신분증은 그 즉시 폐기되고 옛 폰엔 72시간짜리 되돌리기 열쇠만 남음
② 다른 사람이 내 명의로 시도 → 얼굴 불일치로 거절
   새 폰 얼굴 단계에서 바로 막혀 QR이 뜨지 않음. 옛 폰에 「내 명의로 이어받기 시도가 있었어요」 알림 → 신고
③ 옛 폰 분실 → 방문·IC 안내
④ 30일 안에 또 이어받기 → 거절
   30일이 지나면 됨
⑤ 대면 확인 6년 상한
   이어받아도 만료일은 마지막 대면 확인 후 6년을 넘지 않음. 그때가 되면 갱신 대신 방문, IC 주민등록증 전환을 먼저 안내
⑥ 72시간 안 「내가 하지 않았어요」
   새 폰 신분증 폐기, 옛 폰에 다시 발급
⑦ 만료 60일 전 → 3년 갱신
⑧ 멀리서 승인 시도 → 근거리 확인에서 거절(얼굴은 통과했다고 가정한 경우)
   사기범이 QR 화면을 캡처해 보내 피해자 옛 폰으로 찍게 해도, 두 폰이 떨어져 있어 근거리 확인에서 막힘

## 공통기반이 하는 다섯 가지 확인(이어받기 요청, 세부 검사 11개)
1. 옛 신분증 확인: 옛 신분증 서명, 유효기간, 정지·폐기 아님
2. 옛 폰 승인 확인: 승인 서명, 1회용 번호
3. 본인 확인: 얼굴 일치(공통기반 대조), 명의 일치
4. 근거리 확인: 두 폰 가까이(블루투스)
5. 이용 규칙: 72시간 보호, 30일 제한, 6년 상한
※ 얼굴은 QR을 띄우기 전에 공통기반이 먼저 대조합니다. 맞을 때만 새 폰에 QR이 뜹니다.

## 시뮬레이터에 넣은 규칙
- 신분증으로 쓸 수 있는 폰은 언제나 한 대입니다. 이어받는 순간 옛 폰 신분증은 폐기 목록에 올라 효력이 멈춥니다.
- 옛 폰에는 72시간 동안 「내가 하지 않았어요」만 누를 수 있는 되돌리기 열쇠(공통기반이 옛 폰 열쇠에 묶어 서명한 1회용 증표)만 남습니다. 옛 폰이 없으면 분실 신고 창구에서 되돌립니다.
- 새 폰은 72시간 동안 휴대폰 개통·계좌 개설·신분증 재발급(이어받기 포함)이 막힙니다. 일반 신원확인은 됩니다.
- 실물 신분증(창구 확인 또는 IC 카드 태그)으로 6년마다 다시 확인합니다. 만료일은 「받은 날+3년」과 「마지막 대면 확인+6년」 중 이른 날입니다.
- 이어받기는 30일에 한 번, 만료 60일 전에 알림.

## 실제로 동작하는 것과 시뮬레이션
- 얼굴 인증, 본인 명의 확인, 블루투스 근거리 확인, 창구 본인 확인은 시뮬레이션입니다. 화면 버튼이나 시나리오 설정으로 결과를 정합니다. ⑧의 「가정」 표시는 얼굴 인증이 뚫렸다고 보고 진행한다는 뜻입니다.
- 전자서명과 검증은 실제입니다. 브라우저에 들어 있는 암호 기능(WebCrypto)의 ECDSA P-256(지금 널리 쓰는 타원곡선 전자서명)과 SHA-256으로, 가상 발급기관·공통기반·옛 폰·새 폰이 각자 열쇠를 만들고 신분증 발급 서명, 이어받기 승인 서명, 되돌리기 열쇠, 제출 서명을 만들고 검증합니다. 폰 열쇠의 비밀 부분은 밖으로 꺼낼 수 없게 만들었습니다.
- QR은 모양만 흉내 냈고 「QR 촬영」 버튼으로 연결합니다. 연결 코드에는 새 폰 공개키 지문과 1회용 번호가 들어 있습니다.
- 인물(김민수, 1958년생)과 날짜는 모두 가상입니다. 실제 모바일 신분증 앱이나 정부 시스템과 연결되지 않습니다.
- 「검증 기록 내보내기」로 받은 JSON 파일에는 서명값·공개키·서명한 내용이 모두 들어 있어, 브라우저 밖에서도 다시 검증할 수 있습니다(_검사/verify_export.js).
